# FIZZ — Interactive Experience

FIZZ is a scroll-driven interactive web experience designed around the idea of digital energy, movement, creativity, and connection.

The experience transforms as the user scrolls through four interactive scenes, while the central FIZZ core responds with motion, rotation, energy, and visual effects.

## ✨ Features

- Scroll-driven interactive experience
- Four animated scenes
- Interactive FIZZ energy core
- CREATE / GROW / CONNECT / EXPLORE choices
- Dynamic energy and state indicators
- Mouse interaction and parallax effects
- Animated particles and orbital elements
- Scene progress indicator
- Reset Experience button
- Responsive mobile design
- Smooth visual transitions

## 🎨 Experience Flow

### 01 — DIGITAL ENERGY
**EVERYTHING IS IN MOTION.**

The experience begins with the FIZZ core and introduces the idea of digital energy.

### 02 — DISTURB
**CHANGE THE SYSTEM.**

Scrolling changes the state of the system and transforms the FIZZ core.

### 03 — TRANSFORM
**MOTION BECOMES MEANING.**

The core reaches its transformation moment with enhanced motion and visual effects.

### 04 — COMPLETE
**YOU MOVED IT.**

The experience concludes with the FIZZ message:

> CREATE. GROW. CONNECT. EXPLORE.
>
> THAT'S THE FIZZ.
